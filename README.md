# Тренажёр одинэсника

Тренажёр для входа в 1С-разработку с нуля: путь из уроков, термины с интервальными повторениями,
декодер живого сленга, практикум по запросам и банк вопросов с собеседований.

Бэкенда нет — **весь прогресс хранится в `localStorage` браузера** (ключ `odinesnik.v2`).
Страница целиком статическая, её можно открыть даже локальным файлом.

## Что внутри

| раздел | содержание |
|---|---|
| Путь | 9 разделов, 49 уроков, звёзды за прохождение, замки на закрытых |
| Урок | 8–13 упражнений шести типов, жизни, комбо, XP |
| Разбор ошибок | всё, где ошибся, собирается в отдельный прогон; он возвращает жизни |
| Справочник | архитектура, «под капотом», план обучения, ссылки |
| Профиль | серия дней, цель дня, недельный график, настройки |

Материал: 169 карточек терминов, 30 фраз сленга, 20 задач практикума, 37 вопросов
с собеседований, 12 сборок запроса из блоков, 8 упражнений на пропуск в коде.
Из них генерируется около 500 уникальных упражнений.

### Типы упражнений

- выбор определения по термину и термина по определению
- узнавание по живой фразе из рабочего чата
- сопоставление пар
- сборка запроса 1С из блоков
- пропуск в коде
- «расскажи вслух» с эталонным ответом (для собеседований)

## Персонажи

Три маскота получены **трассировкой растровой картинки**, а не рисованием от руки:

1. уменьшение вдвое усреднением — гасит шум генератора;
2. квантование палитры с допуском 30 по евклидову расстоянию в RGB — вышло 39 цветов;
3. связные области по каждому цвету — 186 областей;
4. обход границы по «трещинам» между пикселями, со сбором всех петель
   (внешняя плюс дырки, заливка `evenodd`);
5. упрощение контуров Дугласа–Пекера.

Дальше области размечаются по геометрии, без ручных координат:

| часть | признак |
|---|---|
| белок глаза | светлая область в верхней зоне; плотность около 0.45 — это кольцо с дыркой от зрачка |
| зрачок | тёмное внутри рамки белка |
| блик | светлое внутри рамки зрачка |
| бровь | тёмное вытянутое над линией глаз |
| рот | ниже глаз, у центральной оси; язык — то, что внутри рамки рта |
| оправа | неплотное, перекрывающее глаз, но глазом не являющееся |

Состояния мимики — трансформации тех же трассированных путей
(прищур это `scale(1, 0.45)` по центру глаза, поднятая бровь — сдвиг с зеркальным поворотом).
Дорисованы только те, которых в исходнике физически нет: моргание, дуга радости, веко грусти.

Движок `RIG` подменяет три слоя лица (`.m-brows`, `.m-eyes`, `.m-mouth`), не трогая тело:
холостое моргание каждые 2.4–6 секунд, реакция на верный и неверный ответ, празднование на финале.
Всё уважает `prefers-reduced-motion`.

## Структура

```
index.html            собранная страница для хостинга
dist/artifact.html    то же тело без <head>
build.js              сборка
src/
  data/               содержание: термины, теория, задачи, план, ссылки
  app/                стили и код: движок курса, урок, экраны, мимика
tools/                трассировка растра в SVG и экспорт
tests/                проверки в jsdom
mascots/              SVG персонажей: целые фигуры и отдельные слои
```

## Команды

```bash
npm install
npm run build     # собрать index.html и dist/artifact.html
npm test          # 41 проверка в jsdom
npm run trace     # пересобрать персонажей из tools/source.png
npm run svg       # выгрузить SVG в mascots/
```

## Правка персонажей

В `mascots/` лежат целые фигуры по настроениям и отдельные слои.
У всех файлов одного персонажа **одинаковый `viewBox`** — по нему слои совмещаются обратно.
Подробности в `mascots/README.md`.

## Оговорки по содержанию

- Платформа в 2026 живёт двумя ветками: **8.3.27** (последняя в линейке 8.3, на ней большинство
  внедрений) и **8.5.x** (финальный релиз 8.5.1 — 25 декабря 2025). Версии 8.3.28 не будет.
- Учиться практичнее на 8.3: под неё написаны книги, курсы и почти все рабочие базы.
- Цены курсов и даты потоков собраны в августе 2026 и устаревают быстрее всего остального.

## Что сознательно не скопировано у Duolingo

- **Лиги** — поощряют фарм XP вместо учёбы.
- **Штрафующая модель жизней** — Duolingo сама признала, что новички вдвое чаще остаются
  без сердец. Здесь ошибка при повторе внутри урока жизнь не снимает, серия из пяти верных
  ответов её возвращает, и есть режим «без жизней».

Взята механика, а не оформление: палитра своя, на 1С-жёлтом, персонажи собственные.
